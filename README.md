# Wallpaper Switcher

A Tauri v2 desktop app for browsing, downloading, and setting wallpapers on Wayland via the `awww` daemon.

Built as a simpler alternative to [waypaper](https://github.com/anufrievroman/waypaper).

## Usage

```sh
awww-daemon &

nix develop
npm run tauri dev   # or: npm run tauri build
```

Wallpapers live in `~/Pictures/Wallpapers`. The app shows a grid of everything there. You can also paste an image URL to preview and download it.

## Tech Stack

- **Shell:** Tauri v2
- **UI:** Svelte 5 + SvelteKit SPA + Tailwind CSS v4
- **Wallpaper backend:** [awww](https://github.com/K4rakara/awww)

The backend is swappable via a Rust trait — only `awww` is implemented, but adding others is straightforward.

## Development

```sh
nix develop   # provides cargo, node, webkitgtk, etc.
```

Requires `awww-daemon` running.
